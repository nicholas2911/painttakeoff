# Which ones actually beat the competition

The trap: building all 100 makes us Bluebeam — bloated and confusing.
Our edge is the opposite: **a painter opens it and finishes a quote before
Bluebeam finishes loading.** Strategy picks, in order:

## The Wedge (build first — these 8 win deals)
1. **#67–70 surface/colour/substrate/spray intelligence** — NO competitor
   has painting physics built in; Bluebeam users hack it with Excel.
2. **#21 good/better/best quotes** — painters close more jobs with 3-tier
   pricing; nobody in takeoff does this natively.
3. **#73 paint order list** — from measurements to a Sherwin-Williams
   order in one click. Estimators' daily pain, zero clicks elsewhere.
4. **#38–39 branded proposals** — the quote that looks most professional
   wins residential jobs. This is PaintScout's whole business; ours is
   better because it's measured from the actual plans.
5. **#48–49 pipeline + follow-ups** — turns the tool from "measuring
   app" into "where my business lives" (daily open = retention).
6. **#19/#20 per-room breakdown + rounding** — cheap to build, makes
   quotes trustworthy.
7. **#7 paint-code grouping** — commercial bidders live in finish
   schedules; owning PT-code workflow owns commercial painting.
8. **#82 onboarding sample project** — every competitor loses 50% of
   trials in the first hour; we win them in 10 minutes.

## The Moat (Phase 4 — after Phase 3 gate)
- **#60–63 AI takeoff stack** — Togal/Beam charge $250–300/mo for this
  alone. Bolted onto our painting intelligence, it's the premium tier
  ($149/mo?) that undercuts them by half.
- **#64 email bid-invite parsing** — the user's IMAP idea; with accounts
  in Phase 3 this becomes "bids arrive pre-loaded".
- **#77–81 trade packs** — multi-trade growth without bloating the
  painter UI (each trade = a mode, not a new app).

## Hard rules
- Every feature answers: "does a painting estimator need this to win or
  price a job?" If not, it waits.
- New tools appear only when usable — no grayed-out "coming soon" clutter.
- The dashboard stats/pipeline stay honest: real numbers only.

# The "self-organizing tools" batch (user direction: same tools as them, way more organized)

103. P1 **Auto-naming from the plan's own text** — vector PDFs carry room
     labels ("HOBBY ROOM", "OFFICE 3") with positions. When a measurement
     finishes, suggest the nearest room label as its name. Bluebeam never
     names anything; ours names itself. The kill-shot organization feature.
104. P1 **Zones** (floor / wing / unit) — one-click assign or auto-inherit
     from page; panel + quote + Excel group by zone. Bluebeam "Spaces",
     minus the setup homework.
105. P1 **Auto-coloring by kind or zone** — walls blue, trim amber,
     ceilings violet, openings red; or per-zone palettes. Instant visual
     audit of what's measured.
106. P1 **Panel smart filters** — chips: kind / zone / page / paint code;
     filter → totals update to match (quote just what's filtered).
107. P2 **Visibility toggles per kind** ("show only trim on plan") —
     layers, but one click and zero config.
108. P2 **Tool presets toolkit** — saved starters: "9 ft wall · 2 coats ·
     eggshell" — begin a measurement fully configured.
109. P2 **Duplicate-floor linker** — mark two pages as identical plates;
     measure one, quantities multiply.
110. P2 **Crew checklists per room** — prep / cut / roll / done states for
     the field crew printing from the same file.
111. P2 **Custom tags** on measurements + tag filters.
112. P3 **Room auto-grouping** — measurements snapped inside a Quick Area
     room auto-file under it.
