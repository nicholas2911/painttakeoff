Sample plan PDFs
================

These PDFs are NOT committed to the repo (too large). Re-fetch them from
their public sources and place them in this folder with these exact names.
All were verified as valid PDFs on 2026-08-15; see RESEARCH.md section 1
for details on each set's coverage.

- residential-habitat-page-street-cd-set.pdf
  Habitat for Humanity Philadelphia — Page Street rowhouses, full CD set
  (59 pages, vector, dimensioned, door/window schedules).
- residential-permit-chicago-townhouse.pdf
  Chicago townhouse real permit set (15 pages, vector, 1/4"=1'-0").
- commercial-school-bid-set-princeton.pdf
  High-school renovation bid set excerpt (36 pages, vector, mixed scales,
  many "NOT TO SCALE" detail sheets; ~30 MB big-file stress test).
- commercial-ag-science-missouri-bid-set.pdf
  Ag-science institutional bid set with a real room finish schedule with
  paint codes (22 pages, vector).
- scale-only-student-housing-aau.pdf
  Student housing thesis report, scale-only (156 pages, "1:50" notations,
  no written dimensions; plans are small embedded figures).
- residential-scan-radford-ideal-homes-1909.pdf
  Radford "Ideal Homes" 1909 catalog scan (128 pages, raster/OCR — the
  anisotropic-stretch calibration stress test).

Related fallback candidate (sparse dims + graphic scales), noted in
RESEARCH.md:
  https://www.njuhsd.com/documents/NUHS%20Bldg%20J%20Stair%20Repair_20201104.pdf

If any link is dead, search the file's description — all are public plan
sets from US municipal/educational bid postings and Internet Archive scans.
